# __CT_PROJECT_NAME__

Universal mobile application for iOS, Android, and Web built with React Native and Expo SDK 57.

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Start development server
```bash
# Web browser preview
npx expo start --web

# Android device / emulator
npx expo start --android

# iOS simulator (macOS required)
npx expo start --ios
```

### 📱 Preview with Expo Go
Scan the terminal QR code using the **Expo Go** mobile app on your Android or iOS device.

### 📦 Build for Production
```bash
# Cloud build via EAS (Recommended)
npx eas-cli build -p android --profile preview

# Local prebuild
npx expo prebuild
```
