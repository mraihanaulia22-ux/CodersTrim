# __CT_PROJECT_NAME__

Fullstack PHP monolith built with Laravel 13, Blade MVC, SQLite, and Tailwind CSS.

## 🚀 Getting Started

### 1. Install dependencies
```bash
composer install
```

### 2. Configure environment
```bash
cp .env.example .env
php artisan key:generate
```

### 3. Run database migrations
```bash
php artisan migrate
```

### 4. Start local development server
```bash
php artisan serve
```
Open [http://localhost:8000](http://localhost:8000) in your browser.
