# __CT_PROJECT_NAME__ (Firebase Backend)

Backend-as-a-Service configuration with Firebase Cloud Firestore, Storage, and Security Rules.

## 🚀 Getting Started

### 1. Initialize & Deploy with Firebase CLI
```bash
# Login to Firebase
npx firebase login

# Test locally with Firebase Emulators
npx firebase emulators:start

# Deploy security rules and indexes
npx firebase deploy --only firestore,storage
```
