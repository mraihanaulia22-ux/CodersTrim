# __CT_PROJECT_NAME__

Fullstack React framework built with Next.js 16, App Router, TypeScript, and Tailwind CSS v4.

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Start development server
```bash
npm run dev
```
The application will run on [http://localhost:3000](http://localhost:3000).

### 3. Build for production
```bash
npm run build
npm run start
```
