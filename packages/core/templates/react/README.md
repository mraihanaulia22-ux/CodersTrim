Single Page Application built with React 19, Vite 6, TypeScript, and Tailwind CSS v4.

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Start development server
```bash
npm run dev
```
The application will run on [http://localhost:5173](http://localhost:5173).

### 3. Build for production
```bash
npm run build
```
